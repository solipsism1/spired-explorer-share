# SpIRed collaborator explorer

The page in this repository is encrypted. Open the GitHub Pages link and use the
shared password supplied separately by the owner. No GitHub or ChatGPT account
is required to read it.

Only the encrypted page is published here. The plaintext explorer and password
must never be added to this repository or its history. This is a static explorer,
not a live training-data feed.

Protection uses [StatiCrypt v3.5.0](https://github.com/robinmoisson/staticrypt/tree/v3.5.0).
Use a long random password. This is shared-password encryption, not per-user access
control: recipients can retain or forward decrypted copies. Do not treat password
rotation as revocation of already downloaded content.
